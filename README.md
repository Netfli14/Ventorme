# VentorMe · текущая версия лендинга

Обновление 17 октября 2026: три вопроса, общий маршрут или интерактивный IB A/B, PNG без регистрации и добровольная заявка. RU/EN/KZ/UZ/ZH/TR, две темы, исходное видео маскота и точная ссылка команды 004 сохранены. Анимации построены на GSAP с проектным навыком LottieFiles motion-design.

Заявки и воронка находятся в защищённой панели `/stats/` и используют существующее приватное Blob-хранилище счётчика кликов. Переходы к регистрации, заявки и подтверждённые регистрации различаются.

```sh
npm ci
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
```

Для включения заявок нужны серверные `VENTORME_ADMIN_PASSWORD_HASH` и `VENTORME_SESSION_SECRET`. `npm run admin:setup` создаёт приватный игнорируемый файл настроек; добавьте значения в существующий проект Vercel и выполните повторную публикацию. Без настройки защиты форма не сообщает об успешном сохранении. Автоматическая отправка email не подключена.

[Текущая реализация, настройка и проверка](docs/route-implementation.md).

# Ventorme · Твой следующий шаг

Готовый лендинг и контекстный квиз для школьников 10–12 классов. Next.js App Router, React, TypeScript, Tailwind CSS, Motion, GSAP и Three.js. Шесть полных локалей: `ru`, `en`, `kk`, `uz`, `zh`, `tr`. Две темы по предоставленной палитре, светлая по умолчанию.

## Запуск

Node.js 22+ и npm. Проверенная среда: Node.js 24.19.0.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Открой `http://localhost:3000/ru/`. `/` переводит на русский лендинг. Для проверки:

```bash
npm run typecheck
npm test
npm run build
```

Next.js заранее собирает лендинг, квиз и результат для каждой из шести локалей. Счётчик кликов использует серверный Route Handler и приватное хранилище Vercel Blob; для другого адреса пересобери проект с новым `NEXT_PUBLIC_SITE_URL`.

## Регистрация: команда 004

Ссылка закреплена в `src/lib/config.ts`:

`https://ventorme.ai/register?utm_source=hacknext&utm_campaign=team-004`

Все кнопки регистрации на лендинге, в меню и на странице результата открывают этот адрес в текущей вкладке. Номер 004 сохраняет ведущие нули. Переменные окружения не заменяют номер команды. Ответы квиза не включаются в ссылку.

Регистрация и завершённый онбординг происходят на внешней платформе; клик на кнопку не считается подтверждённой регистрацией.

## Публикация на Vercel

1. Импортируй репозиторий [Netfli14/Ventorme](https://github.com/Netfli14/Ventorme) в свою команду Vercel. Исходники не включают `.env.local`, `node_modules`, `.next`, `out` и материалы конкурса.
2. Framework: Next.js. Install: `npm ci`, Build: `npm run build`; настройки сохранены в `vercel.json`. Лендинг остаётся предварительно собранным, API счётчика работает как Vercel Function.
3. Номер команды 004 уже закреплён в исходниках; отдельная переменная не нужна.
4. На Vercel публичный адрес берётся автоматически из `VERCEL_PROJECT_PRODUCTION_URL` для метаданных и кнопки «Поделиться». При необходимости задай свой HTTPS-адрес через `NEXT_PUBLIC_SITE_URL`. Для другого хостинга укажи эту переменную вручную.
5. Перед приглашением знакомых выполни ручные проверки из `docs/validation.md`, включая настоящую командную ссылку.

Для работы счётчика нужен хостинг с серверным runtime Next.js. Пути используют завершающий `/`.

После подключения GitHub к Vercel коммиты в `main` запускают новую production-сборку; другие ветки получают preview.

## Где менять содержание и оформление

Анимированный фон первого экрана — присланный React-компонент `src/components/ui/data-rain.tsx`. Он лениво загружается в `Hero`, использует Canvas 2D и цвета активной темы. Есть кнопка паузы с переводом на все шесть языков. В скрытой вкладке и за пределами первого экрана цикл остановлен; reduced-motion показывает один статичный кадр. На телефоне уменьшены количество частиц и разрешение canvas.

Папка `src/components/ui` создана для переиспользуемых компонентов; alias `@/components/ui` соответствует структуре shadcn/ui при использовании `src/`. Общие стили расположены в `src/app/globals.css` и подключены в корневом layout. Tailwind CSS 4 и TypeScript уже настроены. DataRain использует только React, дополнительных пакетов и изображений ему не требуется. Для добавления других компонентов shadcn/ui в существующий проект можно выполнить `npx shadcn@latest init`, указав эти пути и сохранив текущую палитру; см. [официальную инструкцию](https://ui.shadcn.com/docs/installation/next).

Код казахского языка — `kk`, обозначение в интерфейсе — KZ. Состояние находится в корневом Provider, поэтому смена локали через селектор сохраняет вопрос и ответы. В `sessionStorage` хранится только версия, шаг и стабильные ID ответов. При запрете хранилища работает состояние React в текущем открытом приложении; перезагрузка без хранилища начинает новый квиз. «Начать заново» удаляет ответы.

## Подключённые инструменты дизайна

Design DNA использован для детерминированного измерения двух референсов и создания профилей. Genjutsu применён в веб-редакции: motion, GSAP, Three.js, mobile, accessibility и статический аудит. Их лицензии и происхождение сохранены при подключении скилов. Three.js и GSAP установлены как библиотеки, поскольку исходные репозитории не являются установочными скилами.

Three.js рисует небольшой компас через SVGRenderer, загружается лениво на компьютере и не использует WebGL-фон. GSAP управляет первым экраном и короткой реакцией компаса; Motion — переключениями примеров, вопросами и результатом. У анимаций есть очистка и reduced-motion. При недоступной декорации остаётся статический Lucide-компас. Локальные Noto Sans и Noto Sans CJK распространяются с OFL; требуемые казахские и турецкие глифы проверены.

Для необязательной регенерации ресурсов используется `scripts/generate-assets.py`, Pillow и fontTools с Brotli. Готовые ресурсы уже включены; обычная сборка не требует Python. При добавлении новых китайских текстов обнови подмножество шрифта этим скриптом, передав папку с оригинальными шрифтами и лицензиями.

## Видео и cookies

Интро пересобрано из исходного MP4 при CRF 14: 1484 × 620, 24 fps, 4.5 с, без звука, с faststart. На телефоне ограничено увеличение горизонтального видео. Воспроизведение обычное, без управления прокруткой. См. `public/media/README.md`.

Баннер cookies переведён на RU, EN, KZ, UZ, ZH и TR. «Принять» разрешает сохранение темы, «Только необходимые» оставляет тему без сохранения между посещениями. Выбор сохраняется на 180 дней. Настройки можно открыть из подвала. Счётчик регистрации работает без cookies и идентификаторов посетителей; рекламные cookies не подключены.

## Счётчик кликов на Vercel

Статистика доступна по `/stats/`: всего нажатий, сегодня и по дням в часовом поясе Алматы. Показаны общие числа, доступные любому, у кого есть ссылка. Данные обновляются в течение минуты. Сбор начинается после публикации этой версии; это клики, а не подтверждённые регистрации или уникальные люди.

Все кнопки используют общий обработчик `sendBeacon` с резервным `fetch(..., { keepalive: true })`. Регистрационная ссылка и UTM команды 004 остаются прямыми. Сервер сохраняет один приватный файл на нажатие с новым случайным ID события, без контактов, ответов квиза или ID посетителя. Одинаковый ID не создаёт второй файл; параллельные клики записываются независимо. Preview и локальная разработка не учитываются.

Подключённое хранилище `ventorme-registration-clicks` использует серверные переменные Vercel. Не помещай `BLOB_READ_WRITE_TOKEN` или OIDC-токены в `NEXT_PUBLIC_*`, исходники или браузер. Для проекта на Hobby работают бесплатные квоты Blob; при их исчерпании счётчик может стать недоступен, переход на платный тариф автоматически не включён. Один клик использует одну advanced operation, просмотр статистики — минимум одну. Это собственный счётчик, а не платные Custom Events Vercel Analytics.
